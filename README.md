# Exact Parametric Closure for Real-Time Safe Control of an Autonomous System among a Hundred Agents

Code for the numerical experiments of the paper, by Riccardo Bonalli (L2S, CNRS, Paris-Saclay University). If you use it, please cite the paper.

Requires Python 3 with numpy, scipy, matplotlib and casadi.

   python build_closure.py            # builds closure.npz
   python run_experiments.py          # runs all experiments: figures, tables.txt, results.pkl
   python run_experiments.py plots    # redraws figures and tables from results.pkl
